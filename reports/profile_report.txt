>>>>> STEP 2.2 — Confirm the grain (one row per VIOLATION)
If one row = one violation, a single inspection (one CAMIS on one
INSPECTION DATE) should appear on MULTIPLE rows.

Example inspection with the most rows: CAMIS=50144090, DATE=03/18/2026 -> 24 rows.

Columns that are CONSTANT across all those rows (the inspection):
    CAMIS           = '50144090'  (n distinct = 1)
    INSPECTION DATE = '03/18/2026'  (n distinct = 1)
    SCORE           = '59'  (n distinct = 1)
    GRADE           = ''  (n distinct = 1)
    INSPECTION TYPE = 'Cycle Inspection / Initial Inspection'  (n distinct = 1)
    ACTION          = 'Violations were cited in the following area(s).'  (n distinct = 1)

Column that VARIES row to row: VIOLATION CODE has 12 distinct values across the 24 rows.
    VIOLATION CODE sequence: ['08A', '08A', '10B', '10B', '04L', '04L', '06C', '04M', '06C', '04M', '10E', '10E', '05D', '05D', '10F', '10F', '09C', '09C', '03A', '03A', '02G', '02G', '28-06', '28-06']

=> CAMIS/DATE/SCORE/GRADE/INSPECTION TYPE are constant while VIOLATION
   CODE differs: grain is one row per violation, not per inspection.

Of 84,635 real inspections, 72,583 (85.8%) span more than one row.
